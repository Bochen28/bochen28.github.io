Warehouse Tools

Phone tools for the warehouse. They run in the browser, work offline after the first start, and can be installed like apps.

Scan every package on a pallet, get the total and the full list, and compare it with the printed list from the system.

Package Finder

Install a tool as an app

iPhone: open the tool in Safari, tap Share ⬆︎, then Add to Home Screen.

Android: open the tool in Chrome, tap ⋮, then Install app (or Add to Home screen).
