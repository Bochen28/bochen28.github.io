# Warehouse Tools

Start page of https://bochen28.github.io: links to the warehouse tools.

- **Pallet Scanner**: https://bochen28.github.io/pallet-scanner/ (repo `pallet-scanner`)
- **Package Finder**: https://bochen28.github.io/package-finder/ (repo `package-finder`)
- **CMR Form**: https://bochen28.github.io/cmr/ (folder `cmr/` in this repo)
- **Flashcards** (learning section): https://bochen28.github.io/flashcards/ (repo `flashcards`)

Most tools are their own repository published with GitHub Pages under this domain; CMR Form lives in the `cmr/`
folder of this repository. To add a tool, publish its repository with Pages (or add a folder here) and add a card
to `index.html`.
